# Whisky Discovery Agent

威士忌探索互動 LLM Agent 展示作品，目標是讓使用者透過對話探索偏好與候選酒款。

## 目前狀態

目前只有專案初始化文件，尚無可執行應用、套件清單、測試或部署。產品功能與驗收案例仍待設計；本文件描述方向，不代表功能已完成。

## 開發方向

- Agent 框架採 Google ADK TypeScript，互動協定採 AG-UI；尚未安裝依賴或完成整合。
- 這是可獨立開發與部署的產品；不依賴其他作品的執行環境。
- MVP 互動流程、資料來源、介面與儲存方式須先確定，再建立可執行骨架。
- 展示先使用明確標示的合成資料，不將未查證資料當成即時價格或庫存。

開發前請讀 [AGENTS.md](AGENTS.md)。目前沒有可執行的安裝、啟動或測試指令。
