# Whisky Discovery Agent

威士忌探索互動 LLM Agent 展示作品，讓新手從口味出發、有經驗的使用者從喜歡的酒款出發，找到下一支想探索的威士忌。

## 目前狀態

目前處於產品規劃階段，尚無可執行應用、套件清單、測試或部署。已確認同時服務入門與進階探索，並採用小型、人工查證的真實酒款庫；完整功能範圍仍待確認。

互動流程、資料契約與驗收草案見 [PRODUCT_SPEC.md](PRODUCT_SPEC.md)。文件中的建議不代表功能已完成，酒款庫也尚未建立。

## 開發方向

- Agent 框架採 Google ADK TypeScript，互動協定採 AG-UI；尚未安裝依賴或完成整合。
- 這是可獨立開發與部署的產品；不依賴其他作品的執行環境。
- MVP 互動流程、資料來源、介面與儲存方式須先確定，再建立可執行骨架。
- 展示採用小型、人工查證的真實酒款庫，保留版本、來源與查核日期；合成資料限於明確標示並隔離的測試情境。
- 來源事實、風味整理與使用者回饋分開保存；未知資訊保持未知，參考價格不代表即時報價或供貨。

開發前請讀 [AGENTS.md](AGENTS.md)。目前沒有可執行的安裝、啟動或測試指令。
